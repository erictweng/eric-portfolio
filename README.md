# Eric Weng — Portfolio

Personal portfolio website for Eric Weng, built to showcase software engineering projects, technical experience, and contact links.

## Tech Stack

- React 19
- TypeScript
- Vite 7
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Local Development

```bash
npm ci
npm run dev
```

## Verification

```bash
npm run lint
npm run build
npm run preview
```

## Project Structure

```text
src/
  components/   Shared UI such as Navbar, Footer, and loading splash
  context/      Theme provider and theme context primitives
  hooks/        Shared React hooks
  sections/     Single-page portfolio sections
  assets/       Source media assets
public/         Static assets copied directly into the build
dist/           Production build output
```

## Deployment

The repository includes a GitHub Pages workflow at `.github/workflows/deploy.yml`. Build output is generated by Vite into `dist/`.

## Notes

- The site currently defaults to dark mode.
- Theme-aware colors are defined as CSS variables in `src/index.css`.
- Live GitHub activity is fetched from the public GitHub Events API.
